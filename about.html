Physics-Based Bouncing Ball Simulation

Exploring AI-generated physics simulations

This project showcases how different AI models approach the same physics simulation problem. Each HTML file contains a complete bouncing ball simulation created by a different AI, demonstrating their unique implementation styles and physics approaches.

AI Models Featured

ChatGPT

OpenAI's conversational AI model with strong code generation capabilities and understanding of physics concepts.

Claude

Anthropic's AI assistant known for careful reasoning and detailed explanations in code generation.

Gemini

Google's multimodal AI model with strong capabilities in code generation and mathematical concepts.

Grok

xAI's model designed for real-time knowledge and straightforward problem-solving approaches.

Kimi

Moonshot AI's model with strong capabilities in Chinese and English language tasks.

MiMo

Xiaomi's AI model with focus on practical applications and efficient implementations.

Qwen

Alibaba's AI model with strong capabilities in code generation and technical tasks.

Physics Features

  • Realistic gravity simulation
  • Energy restitution (bounciness) calculation
  • Smooth 60fps animations
  • Responsive canvas rendering
  • Visual effects and styling
  • Cross-browser compatibility
