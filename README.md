# Physics-Based Looping Bouncing Ball Simulation

A collection of physics-based bouncing ball simulations created by different AI models.

## Project Overview

This project contains 7 HTML files, each implementing a bouncing ball physics simulation using HTML5 Canvas and JavaScript. Each simulation was generated by a different AI model, showcasing how various AI systems approach the same physics simulation problem.

## Simulations

| File | AI Model | Description |
|------|----------|-------------|
| `ChatGPT.html` | ChatGPT | Standard bouncing ball with gravity and restitution |
| `Claude.html` | Claude | Physics simulation implementation |
| `Gemini.html` | Gemini | Google's AI model implementation |
| `Grok.html` | Grok | xAI's model implementation |
| `Kimi.html` | Kimi | Moonshot AI implementation |
| `MiMo.html` | MiMo | Xiaomi's AI model implementation |
| `Qwen.html` | Qwen | Alibaba's AI model implementation |

## Features

- **Realistic Physics**: Gravity, velocity, and energy restitution
- **Canvas Rendering**: Smooth 60fps animations
- **Responsive Design**: Works on different screen sizes
- **Visual Effects**: Gradient backgrounds, shadows, and styling

## How to Run

1. Download any HTML file
2. Open it in a modern web browser (Chrome, Firefox, Safari, Edge)
3. Watch the ball bounce with realistic physics!

## Physics Parameters

Each simulation typically includes:
- **Gravity**: Pulls the ball downward (typically 0.4-0.5)
- **Restitution**: Energy retained after bounce (0.0 = no bounce, 1.0 = perfect bounce)
- **Floor position**: Where the ball bounces
- **Initial velocity**: Starting speed and direction
